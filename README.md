# 📊 Mobile Sales Dashboard

This project is an interactive Mobile Sales Dashboard built using Power BI.

## Features
- Total Sales Analysis
- Total Quantity
- Total Transactions
- Average Sales
- Sales by City
- Sales by Mobile Model
- Payment Method Analysis
- Customer Rating Analysis
- Interactive Filters

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
